### 关键决策
- **DEC-DOCKER-ENTRYPOINT**: entrypoint.sh 使用 `exec "$@"` 支持命令透传
  - **原因**: Docker Compose `command` 会作为参数传给 `ENTRYPOINT`（exec 形式），硬编码 `exec uvicorn` 导致 worker 无法运行 celery
  - **影响范围**: `backend/entrypoint.sh`、`backend/Dockerfile`
  - **回滚条件**: 无需回滚，此为标准做法
- **DEC-PASSLIB-BCRYPT**: 锁定 `bcrypt<4.1` 修复 passlib 1.7.4 不兼容
  - **原因**: bcrypt 4.1+ 移除了 `__about__` 属性并改变了密码长度校验行为，passlib 1.7.4 调用时会抛出 `ValueError: password cannot be longer than 72 bytes`
  - **影响范围**: `backend/requirements.txt`
  - **回滚条件**: 升级 passlib 到 1.7.5+ 或迁移至 `bcrypt` 原生 API 后解除锁定
