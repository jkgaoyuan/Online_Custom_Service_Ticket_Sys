### 关键决策
- **DEC-EXP-001**: Celery prefork worker 中的异步任务应使用局部 engine
  - **原因**: 全局 `engine` 的连接池在多次 `asyncio.run()` 之间复用 asyncpg 连接，导致连接绑定到已关闭的事件循环
  - **影响范围**: `backend/app/tasks/export_tasks.py`、`backend/app/tasks/sla_tasks.py`
  - **参考模式**: `email_tasks.py` 已采用相同做法（注释明确说明 "safe to run in any thread/process"）
- **DEC-EXP-002**: API 主进程必须加载 `celery_app` 才能使 `shared_task` 正确绑定 broker
  - **原因**: `@shared_task` 在导入时需要已初始化的 Celery app；API 容器未加载 `celery_worker.py` 时，`.delay()` 可能使用默认 RabbitMQ broker `amqp://localhost:5672`
  - **影响范围**: `backend/app/main.py`
- **DEC-EXP-003**: 多容器架构中，生成文件的服务和消费文件的服务必须共享 volume
  - **原因**: `api` 和 `worker` 是独立容器，各自的 `/app/exports` 是独立文件系统
  - **影响范围**: `docker-compose.yml`、`docker-compose.prod.yml`
